# Alethia Scoop Bucket

Windows [Scoop](https://scoop.sh) manifests for the [Alethia](https://alethialabs.io) `alethia` CLI.

## Install

```powershell
scoop bucket add alethia https://github.com/alethialabs-io/scoop-bucket
scoop install alethia
```

Update with `scoop update alethia`.

> Manifests here are published automatically by [GoReleaser](https://goreleaser.com) on each `cli-v*` release. Do not edit them by hand.
